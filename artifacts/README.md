# Локальные файлы модели

`prepare_catboost_data.py` создаёт профили поставщиков и поисковый каталог, а `train_catboost.py` — модель `supplier_ranker.cbm`. Для API нужна вся папка с созданными профилями, моделью и `training_report.json` одной версии.

Git хранит код и отчёт о качестве. Исходные CSV, подготовленная выборка, модель и профили исключены из Git. После клонирования их нужно построить на локальных данных или получить готовую папку от команды.

Не копируй эти файлы в `frontend/`: Pages должен содержать только публичный интерфейс. Для Docker подключи папку как volume `/app/artifacts`.
