# Папка для сайта сокомандника

Загрузи сюда файлы своего сайта и замени временный `index.html`.

- Для обычного HTML/CSS/JS входной файл — `frontend/index.html`.
- Для Vite/React положи сюда проект с `package.json`, `package-lock.json` и командой `npm run build`, которая создаёт `frontend/dist/index.html`. Workflow выберет этот вариант автоматически.
- Используй относительные пути к ресурсам. Для Vite установи `base: './'`: сайт Pages размещается под путём репозитория.
- Загрузи изменения коммитом в `main`. Workflow публикует только содержимое этой папки или её `dist`.

На GitHub уже включён **Settings → Pages → Source → GitHub Actions**. Адрес сайта: https://romantamrazov.github.io/RLTTTSK/. Пока будет доступна временная страница; после твоего коммита её заменит твой сайт.

## Контракт для следующего коммита с подключением модели

Поиск отправляет `POST /search` на отдельный HTTPS-сервер API:

```json
{"query":"ремонт автоэвакуатора ОКПД2 45.20.2 ИНН заказчика 7842019044","top_k":10}
```

Ответ содержит `parsed_query`, `mode`, `candidate_count` и массив `recommendations`. В карточке доступны ИНН, название (если известно), описание опыта, `reasons`, `history` и относительный `rank_score`. В режиме точного поиска по ИНН балл равен `null`.

GitHub Pages размещает статический интерфейс. Для подключения модели следующим коммитом понадобятся URL развёрнутого API и URL страницы Pages: добавим адрес API, обработку ответа и разрешённый CORS origin. Адрес `localhost` в опубликованном сайте работать для посетителей не будет.
